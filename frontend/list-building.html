What is List Building Tool?

List Building Tool helps you find decision makers and their verified work emails. You can:

  • Upload domains - Get all decision makers from company websites
  • Search companies - Find companies by industry, size, location
  • Enrich LinkedIn profiles - Add emails to your existing leads

How It Works

Every enrichment request follows this process:

  1. Upload your data - CSV with domains or LinkedIn URLs
  2. We process in background - Watch progress in real-time
  3. Download enriched CSV - Get emails, verification status, and more

Data Sources

We use two data sources to maximize coverage while minimizing costs:

Primary: Internal Database (Free)

Our cached database with millions of contacts. Always checked first.

contacts_db_linkedin contacts_db_name contacts_db_domain

Fallback: Blitz API (Paid)

Used when internal DB has no data. Provides verified emails.

blitz_linkedin blitz_name

Understanding Output Columns

dm_email_source - Where the email came from

dm_email_verified - Email verification status:

  • yes - Email is verified deliverable
  • no - Email found but not verified
  • unknown - No verification data available

row_status - Processing result:

  • enriched - Successfully found email
  • no_contacts - Company found but no contacts
  • not_found - Could not find company

💬 Example queries

Once connected, just talk to Claude Code naturally. Real examples:

Example 1 — Find an endpoint
"I have a list of company domains and I want to find decision-maker emails for each one. Which API endpoint should I use?"
→ Claude calls find_endpoint_for_intent, then tells you to use POST /api/enrichment/flows/domain-enrich for bulk CSV or POST /api/enrichment/enrich for single lookups, with the exact JSON payload and curl example.

"I got HTTP 429 when starting a scraper job. What happened?"

→ Claude reads docs://api-reference and summarizes or searches it for you.

🔐 Authentication

Two methods are accepted. For MCP usage, the API key is all you need.

ActionAPI KeyJWT (login token)
MCP server access✅ Yes✅ Yes
Single-row enrichment (/enrich)✅ Yes✅ Yes
Scraper downloads + resume✅ Yes✅ Yes
CSV upload + bulk jobs❌ No✅ Yes only
API key management❌ No✅ Yes only
💡
API key vs JWT: API keys start with lgp_, never expire, and are perfect for MCP / scripted access. JWTs come from login, expire after 7 days, and are required for CSV upload + bulk jobs.

🧰 Troubleshooting

MCP not connecting?

1. Verify your API key is valid (should return {"status":"ok","mcp_enabled":true}):

curl -s https://listbuilding.eagleinfoservice.com/api/health \
  -H "X-API-Key: lgp_YOUR_KEY"
bash

2. Check the MCP endpoint directly (should return JSON with "serverInfo":{"name":"listbuilding-docs-oracle"}):

curl -s -X POST https://listbuilding.eagleinfoservice.com/mcp/ \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "X-API-Key: lgp_YOUR_KEY" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"test","version":"1.0"}}}'
bash

3. Check settings.json syntax — JSON must be valid (no trailing commas, proper quotes).

4. Restart Claude Code completely — not just reload, fully close and reopen.

"401 Authentication required" error

  • Your API key may be invalid or revoked
  • Check for extra spaces or newlines in the key
  • Generate a new key at Account → API Keys

Claude Code doesn't see the MCP tools

  • Ensure the entry is under "mcpServers" (plural, camelCase)
  • The key name ("listbuilding") can be anything — it's just an identifier
  • Check Claude Code logs for MCP connection errors

❓FAQ

Does the MCP make API calls for me?

No. The MCP is a documentation oracle — it tells you WHICH endpoint and HOW, but you (or your code) execute the calls. This is by design, for security and cost control.

How often does the documentation update?

Automatically. The MCP reads the live OpenAPI spec from the running FastAPI app. When a new endpoint is added and the service restarts, the MCP serves the new spec on the next query.

Is there a daily quota for MCP usage?

No. MCP queries are read-only metadata operations — they do not count against the 50K daily API request quota. Only actual API calls (enrichment, scraping, etc.) count.

Can I use this with Cursor / VS Code / other tools?

Yes. Any MCP-compatible client can connect using the same URL and API key. The server uses the standard streamable HTTP transport.

Can multiple team members use the same MCP server?

Yes. Each person uses their own API key. The MCP server handles concurrent connections (4 gunicorn workers, stateless mode).
